A question about using the library belongs in an
[issue](https://github.com/oxidestack/avro-codec-rs/issues), not in a maintainer's inbox. A vulnerability is
reported privately as [SECURITY.md](SECURITY.md) says; a code-of-conduct report goes to the address in
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
